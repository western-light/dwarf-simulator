# dwarf-simulator

## Interactions

Approchez-vous d'un objet et regardez dans sa direction : le nom de l'action
apparaît lorsqu'il est accessible. Un cadre peut aussi signaler certains objets,
mais pas la voiture. Un appui court sur Interagir
exécute l'action proposée ; maintenez la touche pour afficher les choix, puis
relâchez-la pour confirmer. Dans le menu, utilisez la souris ou les commandes
Précédent/Suivant (1 et 2 au clavier, croix directionnelle à la manette).
Les touches configurées sont affichées à l'écran.

La voiture propose les places Direction et Pédales, avec leur disponibilité.
Une fois assis, un appui court sur Interagir demande l'autre place, et Saut
permet de sortir. Si l'autre place est occupée, l'interaction échange
immédiatement les deux joueurs. Un joueur à pied ne peut pas prendre une place
occupée. Le serveur arbitre les demandes simultanées.
